## 2. 功能规格

### 2.1 食谱收藏（FR-20/21/22）

**需求**：

- 详情页底部新增心形收藏按钮，点击收藏/取消（FR-20）
- 「我的」页新增「我的收藏」入口（带数量角标），进入收藏列表页：按收藏时间倒序、展示缩略图/标题/月龄区间，支持取消收藏、点击进入详情、空态引导（FR-21）
- 食谱列表卡片右上角已收藏角标（FR-22，P2 可选，视进度取舍）

**数据字段**：

- 仅内置食谱可收藏（D21）
- storage 键：`babyfood_favorites_{babyId}`，按宝宝维度隔离
- 结构：`[{ id, createdAt }]`，`createdAt` 为收藏时间戳；取消即移除条目
- 上云映射：`baby_favorites` 表（babyId + recipeId + createdAt），本地结构可直接平移

**实现**（2026-11-09，S1 收藏闭环）：

- 新增 `services/favorites.js`：`getFavorites`（createdAt 倒序）/ `isFavorite` / `count` / `addFavorite`（幂等）/ `removeFavorite` / `toggleFavorite`，storage 键 `babyfood_favorites_{babyId}`，写操作后 bump 数据版本号
- `pages/recipe-detail/`（FR-20）：底部栏占位按钮升级为心形双态（`♡ 收藏` 绿边 / `♥ 已收藏` 红字浅红底 `.fav-active`），点击切换 + toast 反馈；未设宝宝档案时 toast 引导创建；onShow 重新读取状态（兼容从收藏列表取消后返回）
- 新增 `pages/favorites/` 收藏列表页（FR-21，app.json 已注册）：三状态（ready 列表 / empty 空态「去逛逛食谱」/ noBaby「去创建」）；卡片视觉同食谱列表，右侧红心 catchtap 取消收藏并即时移除；onShow 刷新（兼容详情页新收藏后返回）
- `pages/mine/`：菜单「我的收藏」入口接通（原 comingSoon 占位），显示 `N个` 数量角标（无收藏不显示角标）；**仅未设宝宝时整项置灰**（`.menu-disabled`）+ 点击 toast 引导，有宝宝但无收藏时不置灰（2026-11-11 调整）
- FR-22 列表卡片角标（P2）未做，留 S3

> **2026-11-25 FR-22 补齐**：食谱列表页实现已收藏角标——`apply()` 投影时按当前宝宝收藏集计算 `isFav` 字段，卡片标题行内右侧渲染红色 `♥` 角标（`.fav-badge`，行内不占独立空间）；`onShow` 重跑 `apply()` 刷新角标（兼容详情页新收藏/收藏页取消后返回）。未设宝宝时角标全部隐藏。

> **2026-11-09 分页加载**：收藏列表页分页渲染——初始化一次性渲染前 15 条（`PAGE_SIZE = 15`），`onReachBottom` 触底加载下一页（每次 +15），全部加载完显示「— 共 N 条收藏 —」；未加载完时底部提示「上拉加载更多」。全量数据缓存在页面实例（非 data），取消收藏后从第一页重新渲染。

**验收标准**：

- [x] 详情页收藏后收藏列表立即可见、排序正确；取消后实时移除，再收藏时间更新。
- [x] 杀进程重进收藏不丢失；切换宝宝收藏正确隔离。
- [x] 未设宝宝档案时入口置灰并提示引导。
- [x] 收藏超过 15 条时初始化只渲染 15 条，触底追加下一页；全部加载完后底部显示总数。

### 2.2 喂养统计（FR-23~26）

**需求**：

- 「我的」页新增「喂养统计」入口，进入统计页
- 概览三格：累计记录数 / 打卡天数（去重日期数）/ 尝试食谱数（去重食谱数）（FR-23）
- 反应分布：无/过敏/不适 三档条形图（纯 CSS，不引图表库），配色语义化——无=绿、过敏=红、不适=橙；全部为「无」时显示鼓励文案替代图表（FR-24）
- 过敏关注：触发「过敏」反应的食谱排行 + 提示文案（建议就医排查）；无过敏记录时整块隐藏（FR-25）
- 近 30 天打卡热度 + 最常做食谱 Top5（FR-26）
- 支持「本月 / 全部」切换；本月 = 当前自然月（1 号至今）

**数据字段**：

- 不新增存储（D23）：聚合逻辑收敛在新增 `utils/stats.js`，从 `feeding.getLogs(babyId)` 现算
- 输入为记录数组，输出统一聚合对象（summary / reactionDist / allergyRank / heat / topRecipes），页面只做渲染

**实现**（2026-11-11，S2 统计页）：

- 新增 `utils/stats.js`：`buildStats(logs, range)` 纯函数现算，输出 `summary`（累计/打卡天数/尝试食谱三格，天数与食谱均去重）/ `reactionDist`（none/allergy/discomfort 计数）/ `allergyRank`（过敏食谱按次数倒序）/ `heat`（近 30 天逐日计数，含今天）/ `topRecipes`（次数 Top5）；范围 `month`=当前自然月 1 号至今、`all`=全部；不新增存储
- 新增 `pages/stats/` 统计页（FR-23~26，app.json 已注册）：顶部「本月/全部」chip 切换；概览三格（绿数字+分隔线）；反应分布为纯 CSS 横向条形（无=绿 #52C41A、过敏=红 #e53935、不适=橙 #FA8C16，宽度按三档最大值归一），全为「无」时显示鼓励文案替代图表；过敏关注块含就医排查提示、无过敏整块隐藏；30 天热度为 30 根细柱（按最大值归一高度、0 值灰柱、轴标首日与「今天」）；Top5 前三名绿色序号高亮
- 状态机：noBaby（去创建）/ empty（范围内无记录，「去打卡」回首页）/ ready；`pages/mine/` 新增「喂养统计」入口（📊），未设宝宝时 toast 引导
- 每次切换范围或 onShow 均从 storage 现算，无缓存一致性风险

**验收标准**：

- [x] 三格概览与记录逐条核对一致；打卡天数=去重日期数。
- [x] 反应分布配色符合语义；全为「无」时显示良好提示替代图表。
- [x] 过敏关注次数正确、无过敏时隐藏；30 天热度含今天、本月切换范围正确。
- [x] 无记录显示空态引导；未设宝宝档案显示引导不报错。

> **2026-11-25 验收状态更新**：二期 8 条验收项此前已全部真机通过。遗留的图片上传 errno 112 失败经 11-25 复测已恢复正常（判断为当时网络/环境波动，非代码问题），不再排查；二期至此全部闭环。

- [ ] 食谱列表中已收藏的食谱标题右侧显示红心角标，未收藏的不显示。
- [ ] 详情页收藏/取消后返回列表，角标即时更新；未设宝宝时不显示角标且列表正常。
