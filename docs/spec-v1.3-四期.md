## 2. 功能规格

### 2.1 意见反馈（FR-40）

**需求**：「我的」页菜单底部新增「💬 意见反馈」入口，点击打开微信原生「意见反馈」页，用户可提交文字/截图并勾选上传小程序日志；开发者在小程序管理后台「管理 → 用户反馈」查看。

**实现**（2026-11-25）：

- `pages/mine/mine.wxml`：菜单末尾新增 `<button class="menu-item feedback-btn" open-type="feedback">`（原生 button 承载 open-type，无需自建反馈页/后端）
- `pages/mine/mine.wxss`：`.feedback-btn` 重置 button 默认样式（去边框 ::after、白底、行内对齐），与相邻菜单项视觉完全一致
- 反馈数据查看路径：mp.weixin.qq.com → 管理 → 用户反馈；微信公众平台公众号会推送新反馈提醒

**验收标准**：

- [ ] 「我的」页出现「💬 意见反馈」菜单项，样式与其他菜单项一致（hover 无蓝色按钮底、边框圆角正常）。
- [ ] 真机点击打开微信原生意见反馈页，可提交文字与截图；提交后在 mp 后台「用户反馈」可见。

### 2.2 购物清单（FR-41）

**需求**：（待开发前补充细化）从本周菜单读取全部已排格子的食谱，聚合 ingredients 去重，按类别分组输出勾选式采购清单；支持清空勾选进度。
