# 宝宝辅食小程序（BabyFood）产品规格说明书

> 本文档是项目的单一事实来源（source of truth）。任何功能开发前，先在本文件补/改对应小节（需求 → 数据字段 → 验收标准），再据此实现与验收。版本：v0.1（初版）。

## 1. 概述

### 1.1 产品定位
面向 0-3 岁宝宝的辅食推荐与喂养记录微信小程序。帮助家长按宝宝月龄找到适龄辅食，记录每日喂养与过敏反应，避免踩过敏原的坑。

### 1.2 目标用户
0-3 岁宝宝的家长/看护人（新手父母为主）。

### 1.3 核心价值
1. **按月龄推荐**：录入生日，自动算月龄，只推适龄食谱。
2. **过敏安全**：宝宝档案标记过敏原，食谱详情自动做冲突提醒。
3. **喂养闭环**：记录每天吃了什么、有无过敏/不适，可回看。

### 1.4 范围（当前阶段）
- 范围外：多账号体系、支付、社区、电商。

## 3. 功能规格

> 每项功能统一格式：**需求**（做什么）→ **验收标准**（怎样算完成）。

### 3.1 宝宝档案管理
**需求**：新增/编辑/查看宝宝档案。字段：昵称（必填）、生日（必填）、性别（男/女）、过敏原（多选）、头像 emoji。

**验收标准**：
- [ ] 无宝宝时首页引导去新建；新增后列表可见。
- [ ] 昵称或生日为空时，保存被拦截并提示。
- [ ] 生日不可选未来日期。
- [ ] 月龄由生日自动计算，编辑生日后实时预览。

### 3.2 按月龄推荐（首页）
**需求**：根据当前宝宝的月龄，推荐适龄食谱；无宝宝或月龄在纯奶期（0-4 月）时给出对应引导。

**验收标准**：
- [ ] 月龄落在 `[minMonths, maxMonths]` 区间内的食谱才会被推荐。
- [ ] 0-4 月阶段显示"以奶为主，暂不添加辅食"引导，不推食谱。

### 3.3 食谱浏览与筛选
**需求**：按年龄阶段筛选、按标题/食材搜索；详情页展示食材、步骤、营养、标签、难度。

**验收标准**：
- [ ] 阶段筛选与搜索可组合生效，结果为空时有空态提示。
- [ ] 详情页完整展示 ingredients / steps / nutrition / tags / difficulty。

### 3.4 过敏原管理与冲突提醒
**需求**：食谱含过敏原（`allergens` 字段）；宝宝档案有过敏原集合；两者有交集时，详情页高亮冲突提示。

**验收标准**：
- [ ] 宝宝过敏原与食谱 allergens 交集非空时，详情页出现醒目冲突提醒。
- [ ] 8 大常见过敏原在编辑页带 ★ 标注。

### 3.5 食物百科
**需求**：展示食材的建议添加月龄、营养、益处、过敏风险、喂养 tips。

**验收标准**：
- [ ] 百科列表可浏览；点击查看完整信息。
- [ ] 过敏风险（低/中/高）有视觉区分。

### 3.6 喂养打卡
**需求**：为某宝宝某天记录吃了某食谱，标注反应（无/过敏/不适）与备注；记录页按日期回看。

**验收标准**：
- [ ] 打卡需选定宝宝与食谱；反应字段可空。
- [ ] 记录页按日期分组展示；标记"过敏/不适"的记录有醒目样式。

### 3.7 我的
**需求**：入口页（当前为占位）。规划：入口到宝宝列表、收藏、统计等。

**验收标准**：
- [ ] 展示当前环境信息/占位，不影响其他 tab 使用。

## 4. 数据模型

### 4.1 babies（宝宝档案）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 唯一标识 |
| name | string | 是 | 昵称 |
| birthday | string | 是 | 生日 `YYYY-MM-DD` |
| gender | string | 是 | `男` / `女` |
| allergens | string[] | 否 | 过敏原名称数组 |
| emoji | string | 否 | 头像 emoji，默认 `👶` |

> 月龄为**派生字段**，不存储，由 `birthday` 实时计算。

### 4.2 recipes（食谱）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 唯一标识 |
| title | string | 是 | 标题 |
| emoji | string | 否 | 封面 emoji |
| minMonths | number | 是 | 适用最小月龄 |
| maxMonths | number | 是 | 适用最大月龄 |
| desc | string | 否 | 一句话简介 |
| difficulty | string | 是 | `easy` / `normal` / `hard` |
| allergens | string[] | 否 | 含过敏原 |
| ingredients | string[] | 是 | 食材及用量 |
| steps | string[] | 是 | 制作步骤 |
| nutrition | string | 否 | 营养要点 |
| tags | string[] | 否 | 标签 |

### 4.3 ingredients（食材百科）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 唯一标识 |
| name | string | 是 | 名称 |
| emoji | string | 否 | 图标 |
| addMonths | number | 是 | 建议添加月龄 |
| nutrition | string | 否 | 营养 |
| benefit | string | 否 | 益处 |
| allergenRisk | string | 是 | `低` / `中` / `高` |
| tips | string | 否 | 喂养提示 |

### 4.4 feedingLogs（喂养记录）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 唯一标识 |
| babyId | string | 是 | 关联宝宝 |
| date | string | 是 | 日期 `YYYY-MM-DD` |
| recipeId | string | 是 | 关联食谱 |
| recipeTitle | string | 否 | 冗余标题（避免二次查询） |
| emoji | string | 否 | 冗余图标 |
| reaction | string | 否 | `none` / `allergy` / `discomfort` |
| note | string | 否 | 备注 |

### 4.5 常量（`utils/constants.js`）
- **年龄阶段 STAGES**：0-4 / 4-6 / 6-8 / 8-10 / 10-12 / 12-24 / 24-36 月。
- **过敏原 ALLERGENS**：牛奶、鸡蛋、花生、大豆、小麦、坚果、海鲜、芝麻、芒果、菠萝、猕猴桃、虾、蟹、鱼、蜂蜜（前 8 个为 8 大常见过敏原，标 ★）。
- **难度 DIFFICULTY**：easy 简单 / normal 中等 / hard 较难。
- **反应 REACTIONS**：none 无 / allergy 过敏 / discomfort 不适。

### 4.6 待新增数据模型（阶段 2/3，先占位）
- `favorites`：收藏（userId?, recipeId, createdAt）。
- `guides`：月龄指引科普内容（stageKey, title, content）。
- `stats`：喂养统计（可派生，暂不建集合，由 feedingLogs 聚合）。

## 5. 非功能需求

- **离线可用**：当前阶段不依赖后端也能完整跑通（本地数据）。
- **兼容**：微信基础库 ≥ 3.17.1。
- **性能**：首屏/列表数据量在百级内无卡顿。

## 6. 阶段规划（Roadmap）

| 阶段 | 目标 | 关键事项 |
|---|---|---|
| **阶段 1（当前）** | 跑通 MVP 产品闭环 | 已完成 UI 与本地数据；补充 spec 与 git 工作流 |
| **阶段 2** | 内容扩容 + 数据落地 | 食谱 10→100+、食材 12→50+；接云开发，mock 迁云库；内容管理后台 |
| **阶段 3** | 数据反哺 | 喂养统计、收藏、订阅消息提醒、按月龄指引科普 |

## 7. 规格变更流程

1. 任何新功能/改动，先在本文件对应小节补「需求 → 数据字段 → 验收标准」。
2. 实现前出实现计划（改哪些文件、加哪些字段），确认后动手。
3. 完成后对照「验收标准」逐条核对，勾选 `[ ]`。
4. 数据模型变更必须同步更新第 4 节。
5. 本文件随代码一起提交到 git，作为评审与交接依据。
