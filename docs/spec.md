# 宝宝辅食小程序（BabyFood）产品规格说明书

> 本文档是项目的单一事实来源（source of truth）。任何功能开发前，先在本文件补/改对应小节（需求 → 数据字段 → 验收标准），再据此实现与验收。版本：v0.1（初版）。

## 1. 概述

### 1.1 产品定位

面向 0-3 岁宝宝的辅食推荐与喂养记录微信小程序。帮助家长按宝宝月龄找到适龄辅食，记录每日喂养与过敏反应，避免踩过敏原的坑。

### 1.2 目标用户

0-3 岁宝宝的家长/看护人（新手父母为主）。

### 1.3 核心价值

1. **按月龄推荐**：录入生日，自动算月龄，只推适龄食谱。
2. **过敏安全**：宝宝档案标记过敏原，食谱详情自动做冲突提醒。
3. **喂养闭环**：记录每天吃了什么、有无过敏/不适，可回看。

### 1.4 范围（当前阶段）

- 范围外：多账号体系、支付、社区、电商。

## 3. 功能规格

> 每项功能统一格式：**需求**（做什么）→ **验收标准**（怎样算完成）。

### 3.1 宝宝档案管理

**需求**：新增/编辑/查看宝宝档案。字段：昵称（必填）、生日（必填）、性别（男/女）、过敏原（多选）、头像 emoji。

**验收标准**：

- [x] 无宝宝时首页引导去新建；新增后列表可见。
- [x] 昵称或生日为空时，保存被拦截并提示。
- [x] 生日不可选未来日期。
- [x] 月龄由生日自动计算，编辑生日后实时预览。

### 3.2 按月龄推荐（首页）

**需求**：根据当前宝宝的月龄，推荐适龄食谱；无宝宝或月龄在纯奶期（0-4 月）时给出对应引导。

**验收标准**：

- [x] 月龄落在 `[minMonths, maxMonths]` 区间内的食谱才会被推荐。
- [x] 0-4 月阶段显示"以奶为主，暂不添加辅食"引导，不推食谱。

### 3.3 食谱浏览与筛选

**需求**：按年龄阶段筛选、按标题/食材搜索；详情页展示食材、步骤、营养、标签、难度。

**验收标准**：

- [x] 阶段筛选与搜索可组合生效，结果为空时有空态提示。
- [x] 详情页完整展示 ingredients / steps / tips / nutrition / tags / difficulty。

### 3.4 过敏原管理与冲突提醒

**需求**：食谱含过敏原（`allergens` 字段）；宝宝档案有过敏原集合；两者有交集时，详情页高亮冲突提示。

**验收标准**：

- [x] 宝宝过敏原与食谱 allergens 交集非空时，详情页出现醒目冲突提醒。
- [x] 8 大常见过敏原在编辑页带 ★ 标注。

### 3.5 食物百科

**需求**：展示食材的建议添加月龄、营养、益处、过敏风险、喂养 tips；列表右侧信息列**过敏等级在上、月龄标签在下，整体右对齐**。

> **2026-11-06 改版（方案A·双胶囊统一）**：过敏等级由纯文字改为与月龄标签**同款胶囊样式**（padding 4rpx 20rpx、圆角 24rpx、字号 22rpx），按风险档位浅色底+深色字配色：低=浅绿底绿字、中=浅橙底橙字、高=浅红底红字。与月龄绿胶囊上下排列，形成统一的双胶囊视觉。

> **2026-11-06 搜索框吸顶 + 搜索回顶**：搜索框与排序说明整体固定在页面顶部（`position: fixed` + 等高占位块，方案同食谱列表页，规避 sticky 真机热区不跟随问题）；输入搜索词出现结果时列表回到顶部（`wx.pageScrollTo({ scrollTop: 0, duration: 0 })`），清空搜索同样回顶。修复：清除按钮 ✕ 被 input 原生组件遮挡点击无响应，`.search-clear` 提升 `z-index: 2` 并扩大热区。

> **2026-11-06 详情弹窗改版**：食材详情由 `wx.showModal` 改为页面内自定义弹窗（遮罩 + 白卡）：标题居中加粗（emoji+名称），内容**左对齐**五行（建议添加/营养/功效/过敏风险/小贴士），底部「知道了」绿色按钮关闭；点遮罩也可关闭。系统 modal 无法自定义对齐，故改自绘。

**验收标准**：

- [x] 百科列表可浏览；点击打开自定义弹窗查看完整信息，标题居中、内容左对齐。
- [x] 过敏风险（低/中/高）胶囊样式，浅色底+深色字按档位配色，位于月龄胶囊上方。
- [x] 向下滑动列表时，搜索框与排序说明保持不动。
- [x] 输入搜索词出现结果后，列表回到顶部展示；点 ✕ 清空同样回顶。

### 3.6 喂养打卡

**需求**：为某宝宝某天记录吃了某食谱，标注反应（无/过敏/不适）与备注；记录页按日期回看。

**验收标准**：

- [x] 打卡需选定宝宝与食谱；反应字段可空。
- [x] 记录页按日期分组展示；标记"过敏/不适"的记录有醒目样式。

### 3.7 我的

**需求**：入口页（当前为占位）。规划：入口到宝宝列表、收藏、统计等。

**验收标准**：

- [x] 展示当前环境信息/占位，不影响其他 tab 使用。

### 3.9 喂养记录图片上传

**需求**：打卡（record-add）支持为一条记录上传 0-3 张图片。

- 入口 `wx.chooseMedia`（相册+拍照，count=剩余可选数），压缩后单张 ≤500KB、长边 ≤1280px。
- 阶段 1 存本地用户文件目录（`USER_DATA_PATH/babyfood/`）；阶段 2 迁云存储，字段结构不变（`images: string[]`）。
- 列表与首页概览显示缩略图；点击 `wx.previewImage` 全屏预览；编辑时可删可补传；上传失败保留表单内容并可重试。

**验收标准**：

- [x] 3 张上限控制生效，超限提示且「+」置灰。
- [x] 保存后重进小程序图片仍可显示；删除图片重新保存后不再显示。
- [x] 断网上传失败时已填内容不丢失，有明确错误提示。

> **2026-11-06 补充（断网提示）**：保存链路阶段 1 为纯本地存储（storage + `USER_DATA_PATH` 文件），断网不影响数据落盘，页面不跳转、表单数据留在 data 中天然不丢。加固提示：①`chooseImages` fail 回调先用 `wx.getNetworkType` 判断无网络（`networkType === 'none'`），无网提示「当前无网络，无法选择图片」，否则维持「无法打开相册，请稍后重试」；②`save()` catch 时同样区分网络，无网提示「当前无网络，内容已保留，请联网后重试」，否则「保存失败，请重试」；两处失败均不跳转、不清空表单。

- [x] 无图片的旧记录展示不受影响（向后兼容）。

## 3C. 体验优化与缺陷修复（2026-11-05）

### 3.18 上传图片权限前置检查

**需求**：真机点击上传图片若系统权限被拒绝，此前表现为静默无反应（chooseMedia 无 fail 回调）；另外后台《用户隐私保护指引》未声明时真机报 `errno: 112`（已在平台侧配置「选中的照片或视频信息」解决）。

1. 点击上传前先 `wx.getSetting`：相册与相机均被明确拒绝（`scope === false`）时，toast 引导去小程序设置开启（2.5s），不拉起选图；未询问过（undefined）或查询失败则放行，交给系统首询问。
2. `chooseMedia` 增加 fail 兜底：用户主动取消不提示，其余失败 toast「无法打开相册」并打日志。
3. 原选图逻辑抽为独立方法 `chooseImages`。

**验收标准**：

- [ ] 拒绝过相册权限的设备上，点上传出 toast 引导，不弹系统窗。
- [ ] 隐私弹窗（privacy-modal）同意后可正常拉起相册。
- [ ] 用户取消选图无错误提示。

### 3.21 记录列表分页渲染与提示修正（2026-11-05）

**需求**：喂养记录列表的分页逻辑修正——**未满一页（PAGE_SIZE=20 条）时，全部记录必须完整渲染，且底部不显示任何分页提示**（既无「上拉或点击加载更多」也无「已显示全部」）；超过一页后才出现分页提示。

**缺陷背景**：`load(true)`（从打卡/编辑页返回时保留已加载条数）会把 `_renderCount` 冻结在旧值——如原 2 条时返回后仍只渲染 2 条，新增的第 3 条记录被隐藏，且 `2 < 3` 误判为「还有更多」，出现「共 3 条记录还要加载更多」的矛盾提示。

**实现要点**：

- 渲染条数保底公式：`_renderCount = min(max(旧条数, min(PAGE_SIZE, 总数)), 总数)`——保留多页加载状态的同时，保证至少渲染满一页（或全部），新增/删除记录后均正确收敛。
- 新增 `showPaging` 数据字段（`总数 > PAGE_SIZE` 时为 true），分页提示的显示条件由「有记录」改为「超过一页」。

**验收标准**：

- [x] 记录数 ≤ 20 条时：所有记录完整显示，无新增记录被隐藏，底部无任何分页提示。
- [x] 添加记录后返回列表：新记录立即可见，不出现「加载更多」误报。
- [x] 记录数 > 20 条时：显示「上拉或点击加载更多 · 共 N 条记录」，触底/点击加载下一页，全部加载完后显示「已显示全部 N 条记录」。
