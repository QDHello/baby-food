# 宝宝辅食小程序（BabyFood）产品规格说明书

> 本文档是项目的单一事实来源（source of truth）。任何功能开发前，先在本文件补/改对应小节（需求 → 数据字段 → 验收标准），再据此实现与验收。版本：v0.1（初版）。

## 1. 概述

### 1.1 产品定位

面向 0-3 岁宝宝的辅食推荐与喂养记录微信小程序。帮助家长按宝宝月龄找到适龄辅食，记录每日喂养与过敏反应，避免踩过敏原的坑。

### 1.2 目标用户

0-3 岁宝宝的家长/看护人（新手父母为主）。

### 1.3 核心价值

1. **按月龄推荐**：录入生日，自动算月龄，只推适龄食谱。
2. **过敏安全**：宝宝档案标记过敏原，食谱详情自动做冲突提醒。
3. **喂养闭环**：记录每天吃了什么、有无过敏/不适，可回看。

### 1.4 范围（当前阶段）

- 范围外：多账号体系、支付、社区、电商。

## 3. 功能规格

> 每项功能统一格式：**需求**（做什么）→ **验收标准**（怎样算完成）。

### 3.1 宝宝档案管理

**需求**：新增/编辑/查看宝宝档案。字段：昵称（必填）、生日（必填）、性别（男/女）、过敏原（多选）、头像 emoji。

**验收标准**：

- [ ] 无宝宝时首页引导去新建；新增后列表可见。
- [ ] 昵称或生日为空时，保存被拦截并提示。
- [ ] 生日不可选未来日期。
- [ ] 月龄由生日自动计算，编辑生日后实时预览。

### 3.2 按月龄推荐（首页）

**需求**：根据当前宝宝的月龄，推荐适龄食谱；无宝宝或月龄在纯奶期（0-4 月）时给出对应引导。

**验收标准**：

- [ ] 月龄落在 `[minMonths, maxMonths]` 区间内的食谱才会被推荐。
- [ ] 0-4 月阶段显示"以奶为主，暂不添加辅食"引导，不推食谱。

### 3.3 食谱浏览与筛选

**需求**：按年龄阶段筛选、按标题/食材搜索；详情页展示食材、步骤、营养、标签、难度。

**验收标准**：

- [ ] 阶段筛选与搜索可组合生效，结果为空时有空态提示。
- [ ] 详情页完整展示 ingredients / steps / tips / nutrition / tags / difficulty。

### 3.4 过敏原管理与冲突提醒

**需求**：食谱含过敏原（`allergens` 字段）；宝宝档案有过敏原集合；两者有交集时，详情页高亮冲突提示。

**验收标准**：

- [ ] 宝宝过敏原与食谱 allergens 交集非空时，详情页出现醒目冲突提醒。
- [ ] 8 大常见过敏原在编辑页带 ★ 标注。

### 3.5 食物百科

**需求**：展示食材的建议添加月龄、营养、益处、过敏风险、喂养 tips。

**验收标准**：

- [ ] 百科列表可浏览；点击查看完整信息。
- [ ] 过敏风险（低/中/高）有视觉区分。

### 3.6 喂养打卡

**需求**：为某宝宝某天记录吃了某食谱，标注反应（无/过敏/不适）与备注；记录页按日期回看。

**验收标准**：

- [ ] 打卡需选定宝宝与食谱；反应字段可空。
- [ ] 记录页按日期分组展示；标记"过敏/不适"的记录有醒目样式。

### 3.7 我的

**需求**：入口页（当前为占位）。规划：入口到宝宝列表、收藏、统计等。

**验收标准**：

- [ ] 展示当前环境信息/占位，不影响其他 tab 使用。

## 3A. 本期新增需求（2026-11-03 评审，来源：《蹦Food-需求文档-v1.0.md》）

> 决策记录：后端沿用微信云开发（阶段 2 启用）；运营者身份用 openid 白名单（不做邮箱登录）；小店本期不露出；内容以现有 102 条为基线与 36 道新教程合并。

### 3.8 首页改版：今日概览 + 推荐辅食

**需求**：首页由「月龄卡片 + 推荐」升级为「今日概览 + 推荐辅食」聚合页。

1. 今日概览区：仅展示**最近一天**的喂养记录（今天无记录则显示最近有记录的一天，顶部标注日期）；按餐次排序；每条含餐次/食谱名/反应/缩略图/备注摘要；提供「查看全部 >」跳转记录页、「+ 记一笔」快捷打卡。
2. 推荐辅食区：已设宝宝档案时按当前月龄段推荐 6 条食谱（标题显示「适合{name}（X月龄）」）；未设档案显示默认精选 6 条并引导设置档案；提供「换一换」随机刷新（新批次不得与上一批完全重复，候选充足时）；点击进食谱详情。

**验收标准**：

- [ ] 今天新增记录后首页概览即时更新；跨天打开自动回退到最近有记录的一天。
- [ ] 未记录过时概览区显示空态引导，不报错。
- [ ] 宝宝月龄 8 个月时，推荐区只出现 6-8 / 8-10 月段食谱。
- [ ] 「换一换」刷新后与上一批不完全重复（候选 >6 条时）。
- [ ] 首页数据异常时推荐区降级隐藏，不影响概览区。

### 3.9 喂养记录图片上传

**需求**：打卡（record-add）支持为一条记录上传 0-3 张图片。

- 入口 `wx.chooseMedia`（相册+拍照，count=剩余可选数），压缩后单张 ≤500KB、长边 ≤1280px。
- 阶段 1 存本地用户文件目录（`USER_DATA_PATH/babyfood/`）；阶段 2 迁云存储，字段结构不变（`images: string[]`）。
- 列表与首页概览显示缩略图；点击 `wx.previewImage` 全屏预览；编辑时可删可补传；上传失败保留表单内容并可重试。

**验收标准**：

- [ ] 3 张上限控制生效，超限提示且「+」置灰。
- [ ] 保存后重进小程序图片仍可显示；删除图片重新保存后不再显示。
- [ ] 断网上传失败时已填内容不丢失，有明确错误提示。
- [ ] 无图片的旧记录展示不受影响（向后兼容）。

### 3.10 内容合并：36 道教程并入食谱库

**需求**：将《蹦Food》整理的 36 道教程与现有 102 条食谱合并（按标题去重，重名以现有条目为基线补 `cover` 字段；不重复的追加）。新字段：

- `cover: string`——封面图路径（本地 `images/recipes/` 或云存储 URL，均可）
- `sourceNote: string`（可选）——来源标注（阶段 2 运营者发布用）

**验收标准**：

- [ ] 合并后食谱总数 ≥102 且无重复标题。
- [ ] 带 cover 的食谱在列表/详情/首页推荐展示封面图；无 cover 的回退 emoji 展示（向后兼容）。
- [ ] 36 道新教程的月龄映射到现有 STAGES 体系，归段无错漏。

### 3.11 运营者发布（阶段 2，云开发启用后）

**需求**：运营者（openid 在 `operatorWhitelist` 集合中）可发布/编辑/下架食谱，发布后对**所有用户可见**（公开读）；普通用户无感（微信身份静默获取，无登录动作）；浏览完全免登录。  
**验收标准**：

- [ ] 白名单外用户调用发布接口被拒绝（云函数侧校验，前端仅做 UI 隐藏）。
- [ ] 发布的食谱即时出现在所有用户的食谱列表；下架后不再展示但数据保留。
- [ ] 内置/合并食谱不可被运营者删除。
- [ ] `sourceNote` 选填，未填展示「本站整理」。

### 3.12 小店（本期不实现，仅预留）

**需求**：本期**不露出任何小店入口与页面**（tabBar 保持 4 个）。仅约定：预留 `shop` 相关目录命名与数据结构文档，后续版本再启用。

### 3.13 PC 内容管理（阶段 2，零开发方案）

**需求**：阶段 2 直接使用**微信云开发控制台**管理食谱/教程数据（增删改查、上传图片），不自建网页后台；自定义网页后台列为后续可选项。

**验收标准**：

- [ ] 云数据库集合与字段命名对控制台管理友好（见第 4 节）。

## 4. 数据模型

### 4.1 babies（宝宝档案）

| 字段        | 类型       | 必填 | 说明               |
| --------- | -------- | -- | ---------------- |
| id        | string   | 是  | 唯一标识             |
| name      | string   | 是  | 昵称               |
| birthday  | string   | 是  | 生日 `YYYY-MM-DD`  |
| gender    | string   | 是  | `男` / `女`        |
| allergens | string[] | 否  | 过敏原名称数组          |
| emoji     | string   | 否  | 头像 emoji，默认 `👶` |

> 月龄为**派生字段**，不存储，由 `birthday` 实时计算。

### 4.2 recipes（食谱）

| 字段          | 类型       | 必填 | 说明                                                  |
| ----------- | -------- | -- | --------------------------------------------------- |
| id          | string   | 是  | 唯一标识                                                |
| title       | string   | 是  | 标题                                                  |
| emoji       | string   | 否  | 封面 emoji（无 cover 时回退展示）                             |
| cover       | string   | 否  | 封面图路径/URL（3.10 新增）                                  |
| minMonths   | number   | 是  | 适用最小月龄                                              |
| maxMonths   | number   | 是  | 适用最大月龄                                              |
| desc        | string   | 否  | 一句话简介                                               |
| difficulty  | string   | 是  | `easy` / `normal` / `hard`                          |
| allergens   | string[] | 否  | 含过敏原                                                |
| ingredients | string[] | 是  | 食材及用量                                               |
| steps       | string[] | 是  | 制作步骤（含时间/火候/手法等细节）                                  |
| tips        | string[] | 否  | 做法说明（制作要点/安全提醒/过敏观察）                                |
| nutrition   | string   | 否  | 营养要点                                                |
| tags        | string[] | 否  | 标签                                                  |
| sourceNote  | string   | 否  | 来源标注（3.10/3.11 新增，选填）                               |
| status      | string   | 否  | `published`（默认）/ `offline`（3.11 运营者下架用；本地内置数据不写此字段） |

### 4.3 ingredients（食材百科）

| 字段           | 类型     | 必填 | 说明              |
| ------------ | ------ | -- | --------------- |
| id           | string | 是  | 唯一标识            |
| name         | string | 是  | 名称              |
| emoji        | string | 否  | 图标              |
| addMonths    | number | 是  | 建议添加月龄          |
| nutrition    | string | 否  | 营养              |
| benefit      | string | 否  | 益处              |
| allergenRisk | string | 是  | `低` / `中` / `高` |
| tips         | string | 否  | 喂养提示            |

### 4.4 feedingLogs（喂养记录）

| 字段          | 类型       | 必填 | 说明                                   |
| ----------- | -------- | -- | ------------------------------------ |
| id          | string   | 是  | 唯一标识                                 |
| babyId      | string   | 是  | 关联宝宝                                 |
| date        | string   | 是  | 日期 `YYYY-MM-DD`                      |
| recipeId    | string   | 是  | 关联食谱                                 |
| recipeTitle | string   | 否  | 冗余标题（避免二次查询）                         |
| emoji       | string   | 否  | 冗余图标                                 |
| reaction    | string   | 否  | `none` / `allergy` / `discomfort`    |
| note        | string   | 否  | 备注                                   |
| images      | string[] | 否  | 图片路径数组，0-3 张（3.9 新增；本地路径或云存储 fileID） |

### 4.7 operatorWhitelist（运营者白名单，阶段 2）

| 字段        | 类型     | 必填 | 说明               |
| --------- | ------ | -- | ---------------- |
| openid    | string | 是  | 运营者微信 openid（主键） |
| note      | string | 否  | 备注（如「店长」）        |
| createdAt | date   | 否  | 加入时间             |

### 4.5 常量（`utils/constants.js`）

- **年龄阶段 STAGES**：0-4 / 4-6 / 6-8 / 8-10 / 10-12 / 12-24 / 24-36 月。
- **过敏原 ALLERGENS**：牛奶、鸡蛋、花生、大豆、小麦、坚果、海鲜、芝麻、芒果、菠萝、猕猴桃、虾、蟹、鱼、蜂蜜（前 8 个为 8 大常见过敏原，标 ★）。
- **难度 DIFFICULTY**：easy 简单 / normal 中等 / hard 较难。
- **反应 REACTIONS**：none 无 / allergy 过敏 / discomfort 不适。

### 4.6 待新增数据模型（阶段 2/3，先占位）

- `favorites`：收藏（userId?, recipeId, createdAt）。
- `guides`：月龄指引科普内容（stageKey, title, content）。
- `stats`：喂养统计（可派生，暂不建集合，由 feedingLogs 聚合）。

## 5. 非功能需求

- **离线可用**：当前阶段不依赖后端也能完整跑通（本地数据）。
- **兼容**：微信基础库 ≥ 3.17.1。
- **性能**：首屏/列表数据量在百级内无卡顿。
